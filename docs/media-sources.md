# Development catalog and licensing

Seed data is opt-in via infrastructure/scripts/seed-demo.sql. All six records describe real Blender open films; descriptions are original summaries, durations rounded to minutes, and unrated means no jurisdiction-specific rating is asserted. Artwork is original VYBE editorial SVG illustration. No official posters or film logos are used. No media files are distributed in phase 1.
