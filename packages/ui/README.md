# UI design system

The first consumer lives in `apps/web/src/components`. Tokens are defined in `apps/web/src/app/globals.css`: charcoal #101310, lime #c2f18c, warm ivory #f0f1e9. Shared extraction waits for a second consumer. Components include Button styles, TitleCard, ErrorBox, Shell, forms and loading states. All motion respects reduced-motion preferences.

Typography uses a system sans serif and Georgia editorial accents, avoiding remote font dependencies. Original procedural SVG artwork is locally bundled and identified as editorial art. No third-party film posters are redistributed.
